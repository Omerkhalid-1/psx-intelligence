Methodology notes

  • Prices come from stored daily bars (self-hosted psxdata-api). Splits and bonus issues are adjusted using cited corporate actions; cash dividends are not.
  • A few provider bars have a high/low that does not contain the open/close. They are flagged at ingestion, and the engine widens their range to contain the body.
  • All indicators are causal: a value for a session uses only that session and earlier ones (verified above).
  • The indicator balance counts directional readings only; descriptive readings (volatility level, volume level, beta, drawdown, zones) carry no direction.
  • Walk-forward tests in this project found no forecasting skill over a no-change baseline for models built on these indicators. Readings describe; they do not predict.
